# Kafka

## Components

1. **Zookeeper:** Manages and coordinates the Kafka brokers.
2. **Topics:** Categories or feeds where records (messages) are published.
3. **Broker:** A single Kafka server that handles read/write requests.
4. **Partition:** A division of a topic that allows for scalable, parallel processing.
5. **Offset:** A unique, sequential ID assigned to messages within a partition.
6. **Consumer:** An application that reads data from a topic.
7. **Producer:** An application that writes data to a topic.
8. **Cluster:** A group of Kafka brokers working together.
9. **Consumer Groups:** A set of consumers cooperating to read from a topic in parallel.
